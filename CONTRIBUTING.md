Contributing and AI Usage Disclaimer
We understand fully that AI is used widespread in programming, and now modding too. We can't stop it here, but we can say what we're comfortable with you doing once you download this code.

YOU CAN: Use LLMs to reverse engineer the code and understand how it works, mainly using it as a tool to help with integrating and/or debugging. You can also use it to suggest better ways of implementing fixes, or leaving comments above functions for documentation purposes.

DO NOT: Throw this code into an AI Model and use it to vibecode 500 different new additions to the game, or port characters, UI, Quests, etc from other Borderlands (or non) games. If you do that, we do not want to see it.

If you plan on contributing to the overall progress of BLOL, we ask that you understand the code you are submitting, rather than putting in a fix for an issue because the AI told you it would fix it.
